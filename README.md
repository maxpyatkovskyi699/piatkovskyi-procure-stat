# ProcureStat — Моніторинг публічних закупівель Prozorro

## Про проєкт

- Проєкт розробляється для вирішення задачі автоматизованого збору, аналізу та прозорого моніторингу даних щодо публічних закупівель в Україні.
- Головними користувачами системи є аналітики, громадські спостерігачі, замовники та учасники тендерів, яким потрібен швидкий доступ до аналітики ринку та виявлення можливих аномалій у закупівлях.
- Система працює з масивом даних про оголошені та проведені закупівлі, включаючи інформацію про тендери, предмети закупівель, очікувані вартості, замовників та остаточні суми договорів.
- Первинне джерело даних — відкритий офіційний REST API системи Prozorro (Open Contracting Data Standard), який надає безкоштовний доступ до повного реєстру закупівель.
- Обсяг даних є достатнім для глибокого статистичного аналізу, оскільки API забезпечує доступ до десятків тисяч актуальних та історичних записів із можливістю ітеративної вибірки.
- Автоматизоване завантаження через API виключає ручне введення, забезпечує високу точність даних та дозволяє реалізувати регулярну синхронізацію без порушення правил використання сервісу.

## Швидкий старт та запуск

### 1. Системні вимоги

- Python 3.12+
- Git

### 2. Встановлення та налаштування оточення

```powershell
# Клонування репозиторію
git clone https://github.com/maxpyatkovskyi699/piatkovskyi-procure-stat.git
cd piatkovskyi-procure-stat

# Створення та активація віртуального оточення
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Оновлення pip та встановлення проекту в режимі розробки
python -m pip install --upgrade pip
pip install -e .
```
